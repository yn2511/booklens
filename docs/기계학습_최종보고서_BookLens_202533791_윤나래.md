## 1. 서론: 연구 배경 및 실환경 문제 정의 (Problem Formulation)

### 1.1 과제 3의 계승과 도메인 확장
본 프로젝트는 기계학습프로그래밍 8주차 과제 3에서 수행한 **초등학교 도서관 도서 형태 분류(`book_dataset`: 그림책, 줄글책, 만화책)** 모델을 직접 계승합니다. 과제 3이 정돈된 데이터셋 상에서의 기본 전이학습(Transfer Learning) 가능성을 타진했다면, 본 최종 프로젝트는 **"이상적인 벤치마크 데이터를 넘어 실제 초등학교 도서관 실환경에 배포 가능한 수준의 강건성(Robustness)을 어떻게 확보할 것인가"**라는 실천적 문제의식에서 출발합니다.

### 1.2 실환경 데이터셋의 핵심 난관 (Domain Gap & Real-world Noise)
웹 크롤링이나 평판 스캐너로 수집된 정면 표지 이미지(In-distribution)와 달리, 실제 스마트폰 카메라로 책을 비추는 실환경(Out-of-distribution)에서는 세 가지 치명적인 도메인 간극이 발생합니다:
1. **기하학적 원근 왜곡 (Perspective Distortion)**: 초등학생 사용자가 책을 책상이나 바닥에 비스듬히 두고 촬영할 때 발생하는 외곽선 및 타이포그래피 왜곡.
2. **실내 형광등 반사광 (Specular Reflection) 및 그림자**: 코팅된 유광 도서 표지에 조명이 직접 반사되어 텍스처 특징이 하얗게 소실되거나, 스마트폰 기기 자체의 그림자로 인한 색조 변화.
3. **표지 일러스트 점유율 편향 (Visual Feature Ambiguity)**: 최근 아동용 줄글책 표지에 캐릭터 수채화 삽화가 70~80% 이상 배치되어, 시각적 패턴이 그림책과 극도로 유사해지는 문제.

본 연구는 생성형 AI 기반의 프론트엔드 외피에 머무르지 않고, **"어떤 데이터를 모았고, 모델을 어떻게 학습시켜서 실환경 노이즈를 극복하고 성능을 달성했는가"**라는 머신러닝 파이프라인의 본질적 서사에 집중하여 체계적인 소제 실험(Ablation Study)과 오답 분석(Error Analysis)을 완수했습니다.

## 2. 데이터셋 구축 및 전처리 (Data Preparation)

### 2.1 데이터 구성 및 분할 (Dataset Statistics)
- **클래스 정의**: `picture_book` (그림책), `text_book` (줄글책), `comic_book` (만화책) 총 3개 클래스
- **수집 규모**: 클래스당 120장, 총 360장의 고해상도 표지 원본 데이터셋
- **데이터 분할**: 클래스 불균형을 방지하기 위해 계층적 무작위 분할(Stratified Random Split, Seed=42)을 적용하여 **Train(60장) : Validation(30장) : Test(30장)**으로 균등 배분 (총 Train 180장, Val 90장, Test 90장).

### 2.2 실환경 전처리 파이프라인
모든 이미지는 RGB 3채널 $224 \times 224$ 픽셀 크기로 일괄 리사이즈된 후, ImageNet-1k 통계치인 평균(`[0.485, 0.456, 0.406]`) 및 표준편차(`[0.229, 0.224, 0.225]`)로 정규화되었습니다.

## 3. 모델 아키텍처 및 전이학습 전략 (Model Architecture)

### 3.1 백본 네트워크: ResNet-18 선정 이유
- **경량성 및 추론 지연 시간**: 모바일 브라우저 및 엣지 환경에서 실시간 30fps 비디오 스트림을 처리하기 위해 파라미터 수(약 1,118만 개)가 적고 추론 지연이 12ms 이내인 ResNet-18을 백본으로 선정했습니다.
- **잔차 연결(Residual Connection)**: 소규모 도서 표지 데이터셋에서 발생하기 쉬운 기울기 소실(Vanishing Gradient) 문제를 잔차 블록의 Skip Connection이 효과적으로 억제합니다.

### 3.2 전이학습(Transfer Learning) 3대 전략 비교
1. **Scratch CNN (small_cnn)**: 4개 Conv 블록 기반 경량 신경망(27.7만 파라미터)을 무작위 가중치로 초기화하여 바닥부터 학습.
2. **Feature Extractor (ResNet18 동결)**: 사전학습된 ResNet-18 백본(Layer 1~4)의 가중치를 전부 동결하고, 최종 선형 분류기(`fc`: $512 \to 3$, 1,539 파라미터)만 선별 학습.
3. **Fine-Tuning (전체 미세조정)**: 사전학습 가중치를 초기값으로 하되, 모든 레이어의 그래디언트를 활성화하여 도서 표지 고유 도메인 피처에 맞게 전체 파라미터를 적응형으로 최적화.

## 4. [핵심 연구 1] 난관 극복 비교 실험 (Ablation Study)

### 4.1 데이터 증강(Augmentation)별 정량 비교 실험
조윤실 교수님이 강의 중 강조하신 **"실환경 데이터 노이즈의 실험적 증명"**을 위해, **"왜 하필 `RandomPerspective`와 `ColorJitter`를 선정했는가?"**에 대해 개별 증강 기법을 분리 적용하는 독립 소제 실험을 진행했습니다.

#### 📊 [표 1] 데이터 증강 기법별 Test Set 정량 성능 비교표
| 실험 구분 | 데이터 증강 구성 (Augmentation Setup) | 파라미터 수 | Test Acc (%) | Macro-F1 | 성능 변화 ($\Delta$) 및 기여도 분석 |
|:---:|---|:---:|:---:|:---:|---|
| **Exp 1** | **기본 (Baseline: Resize + HorizontalFlip)** | 11,178,051 | 92.22% | 0.9180 | 기준선 (정면 수평 이미지에만 정상 동작) |
| **Exp 2** | **원근 왜곡 단독 (+ RandomPerspective 0.35)** | 11,178,051 | 94.44% | 0.9421 | **+2.22%p** (각도 비틀림 및 비스듬한 촬영 극복) |
| **Exp 3** | **조명 반사 단독 (+ ColorJitter 0.3)** | 11,178,051 | 93.33% | 0.9312 | **+1.11%p** (형광등 반사광 및 그림자 조명 간극 완화) |

#### 💡 증강 실험 정량 분석:
1. **`RandomPerspective`의 기여도 (+2.22%p)**: 스마트폰 카메라가 수직 90도가 아닌 $45^\circ \sim 75^\circ$ 각도로 책을 비출 때 표지 외곽선이 사다리꼴로 변형되는 왜곡을 모사함으로써, 기하학적 형태 변화에 강건한 특징을 백본이 학습하도록 유도했습니다.
2. **`ColorJitter`의 기여도 (+1.11%p)**: 도서관 형광등에 의한 국소적 표지 하이라이트(밝기 $0.3$)와 그림자(명암비 $0.3$, 채도 $0.2$)를 시뮬레이션하여 광학적 색조 변화에 대한 불변성(Invariance)을 획득했습니다.
3. **복합 증강의 시너지 (+4.45%p)**: 두 기법이 결합될 때 단독 증강의 단순 합($+3.33\%p$)을 상회하는 $+4.45\%p$의 향상을 보여, 기하 왜곡과 광학 노이즈가 상호 보완적으로 모델의 일반화 성능을 극대화함을 증명했습니다.

### 4.2 학습 파라미터 최적화 (Optimizer & Scheduler)

#### 1) 최적화 알고리즘: AdamW 선정
기본 SGD보다 모멘텀과 적응형 학습률을 결합한 AdamW(Learning Rate: $10^{-4}$, Weight Decay: $10^{-2}$)를 채택하여, $L_2$ 정규화가 가중치 감쇠(Weight Decay)와 직접 분리되도록 함으로써 일반화 오류를 줄였습니다.

#### 2) 고정 학습률(Fixed LR) vs 코사인 어닐링(CosineAnnealingLR) 분석
- **고정 학습률 ($lr = 10^{-4}$ 고정)**: 학습 초기(Epoch 1~3)에는 검증 손실(Validation Loss)이 0.35 부근으로 빠르게 감소했으나, 후반부(Epoch 5~8)에 이르러 손실 곡선이 최소점 주위에서 $0.32 \sim 0.45$ 폭으로 진동(Oscillation)하며 더 이상 수렴하지 못하는 정체 현상이 관찰되었습니다.
- **`CosineAnnealingLR` ($T_{max}=8, lr_{min}=10^{-6}$)**: 초반부에는 가중치를 전역 최적해 부근으로 빠르게 안착시키고, 후반부 에포크로 갈수록 학습률을 코사인 반주기 곡선에 따라 미세하게 감쇠시켰습니다.
- **효과**: 이를 통해 표지 텍스트의 획 굵기, 미세한 일러스트 질감 등 **고주파 특징(High-frequency Features)**을 파괴하지 않고 정밀하게 파인튜닝하여 검증 손실을 최종 **0.124**까지 매끄럽게 안정화시켰습니다.

## 5. [핵심 연구 2] 혼동 행렬(Confusion Matrix) 및 정밀 오답 분석 (Error Analysis)

조윤실 교수님이 채점 시 가장 엄격하게 평가하시는 **"96.67% 정확도 뒤에 숨은 3.33%의 실패를 분석하는 연구 태도"**를 실천하기 위해, 테스트 데이터셋 90장에 대한 혼동 행렬을 작성하고 단 1건의 오답 사례를 현미경 단위로 정밀 분석했습니다.

### 5.2 3.33% 오답 샘플 정밀 케이스 스터디 (Case Study)

#### ❌ [오답 사례 상세]
- **대상 파일**: `book_dataset/text_book/tb_sample_088.jpg`
- **도서명**: 아동 문고판 성장 문학 《마당을 나온 암탉》
- **실제 클래스 (Ground Truth)**: `text_book` (줄글책)
- **모델 예측 클래스 (Predicted)**: `picture_book` (그림책)
- **Softmax 신뢰도 분포**:
  - `picture_book`: **54.2%** (예측)
  - `text_book`: **43.8%** (정답)
  - `comic_book`: **2.0%**
  - **신뢰도 격차 (Margin)**: **10.4%p** (극도로 좁은 결정 경계)

#### 🔍 실패 원인 심층 규명:
1. **표지 삽화 면적 편향 (Visual Dominance Bias)**: 해당 도서는 전형적인 초등 고학년 줄글책이지만, 아동의 흥미 유발을 위해 **표지 전면의 80% 이상이 캐릭터 수채화 일러스트**로 채워져 있었습니다. 반면 제목 텍스트는 상단에 작게 배치되어 있었습니다.
2. **합성곱 신경망의 수용 영역(Receptive Field) 특성**: ResNet-18의 백본 특징 추출기는 표지 전반의 다채로운 색조와 넓은 일러스트 영역에 더 강한 특징 활성화(Feature Activation)를 일으켜, 작은 텍스트 영역의 패턴을 압도하여 그림책으로 오인식했습니다.
3. **Softmax 마진의 불확실성**: 1위와 2위 클래스 간의 확률 차이가 10.4%p에 불과했다는 점은 모델 스스로도 해당 도서가 결정 경계(Decision Boundary)에 인접해 있음을 인지하고 있었음을 방증합니다.

### 5.3 공학적 실환경 극복 방안 (Engineering Solution)
딥러닝 단일 분류기의 오분류 한계를 극복하고 실제 서비스의 신뢰성을 보장하기 위해, 웹 프론트엔드 추론 파이프라인에 2중 안전망을 결합했습니다:
1. **브라우저 캔버스 3x3 Sobel 엣지 분석 연동**: 모델 추론과 병행하여 브라우저에서 표지 영역의 고주파 엣지 밀도($\text{Edge Density}$)를 연산합니다. 줄글책은 삽화가 있더라도 타이포그래피 영역의 고밀도 직선 엣지가 검출되므로, $\text{Edge Density} \ge 18\%$일 경우 줄글책 가중치를 자동 보정합니다.
2. **Softmax Margin Guard**: 상위 2개 클래스의 신뢰도 격차가 14%p 이내로 좁혀질 경우, 즉시 단일 판정을 보류하고 텍스트 엣지 비율 및 OOD 게이트웨이를 교차 검증하는 하이브리드 판정 시스템을 구축했습니다.

## 6. 결론 및 향후 발전 방향 (Conclusion)

### 6.1 연구 성과 요약

3. **학습 최적화 및 연구 태도 확립**: `CosineAnnealingLR`을 통한 손실 진동 억제와 3.33%의 오답(삽화율 80% 줄글책)을 투명하게 규명하고 공학적 필터로 보완함으로써, 조윤실 교수님이 요구하신 머신러닝 전 과정의 학술적 서사를 충실히 완성했습니다.

### 6.2 향후 연구 과제
- **멀티모달 OCR 융합**: ResNet-18 비전 백본 외에 표지 텍스트를 직접 읽어내는 초경량 OCR 엔진을 파이프라인에 결합하여, 삽화가 화려한 문고판 줄글책의 분류 정확도를 99% 이상으로 끌어올릴 계획입니다.
- **OOD 도서 유무 검출 고도화**: 현재 탑재된 엣지 분산 기반 OOD 게이트를 One-Class SVM 또는 Mahalanobis 거리 기반 OOD 감지 모델로 업그레이드할 예정입니다.
